# Stabilizing Bulk Orders on Finite Rydberg Atom Simulators

This repository contains code to implement DMRG (and related analysis subroutines) for the paper ***Stabilization of bulk quantum orders in finite Rydberg atom arrays***. Relevant output data (log) files are also provided. 

Link to the paper: [arXiv:2604.18890](https://arxiv.org/abs/2604.18890).

**Authors**: Y. M. Lokare and M. J. Coley-O'Rourke.
